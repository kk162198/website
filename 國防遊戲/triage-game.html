檢傷分類
滑動救援

發生大量傷患事件，你是第一位到場的救護員。每位傷患你有 20 秒：親手檢查他的狀況，聽他怎麼回應，再決定該給哪一種顏色的檢傷卡。

怎麼檢查

  • 📢 喊話：「能走的人請走過來！」看他會不會自己走
  • 點臉：拍肩呼叫，請他握你的手，看意識
  • 點胸口：看胸部起伏，數呼吸次數
  • 點手腕：摸橈動脈脈搏
  • 點指尖：按壓指甲，看微血管回填幾秒

START 檢傷原則（照順序判斷）

  1. 能自己走路？能 → 綠色
  2. 有呼吸？沒有 → 打開呼吸道；仍沒有 → 黑色，恢復呼吸 → 紅色
  3. 呼吸每分鐘超過 30 次？是 → 紅色
  4. 循環：回填超過 2 秒或摸不到手腕脈搏 → 紅色
  5. 意識：無法聽從簡單指令 → 紅色
  6. 以上都沒有 → 黃色
→右滑：紅色 立即處置
↑上滑：黃色 延遲處置
←左滑：綠色 輕傷
↓下滑：黑色 無生命徵象

小技巧：檢查照 START 的順序做，一找到決定性的結果就可以分類，不需要全部檢查。內容依照 START 檢傷分類法編寫，報告前請對照課本確認。

  1. 能自己走路嗎？能 → 綠色；不能 → 往下
